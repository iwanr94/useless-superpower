One line naming a hilariously useless superpower, written to
`/output/entry.txt`.

## The line

> I can summon any object I've ever lost - but it only shows up three days after I've already bought a replacement.

The setup is a genuinely handy power — summoning anything you've lost.
The punchline is the timing: it only arrives after you've already paid
for a replacement, so the power exists purely to make you own two of
everything you lose.

## Run

```bash
python3 main.py
```

Writes `/output/entry.txt` as UTF-8, one line, well under the 200-character
limit. Standard library only, no network.
